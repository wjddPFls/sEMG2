\# sEMG Step 2



\## 1. 프로젝트 개요



이 프로젝트에서는 sEMG 신호에서 시간영역 특징을 추출하고 세 가지 머신러닝 모델의 분류 성능을 비교하였다.



사용한 모델은 SVM, Random Forest, XGBoost이다. 동일한 학습 데이터와 테스트 데이터를 이용해 Accuracy, Precision, Recall, F1-score를 측정하였고 혼동행렬을 통해 클래스별 오분류를 분석하였다. 추가로 파일 단위 5-fold 교차검증과 대응표본 t-검정을 수행하였다.



\## 2. 데이터 및 전처리



\### 2.1 데이터 구성



| 항목 | 내용 |

|---|---|

| 원본 데이터 | sEMG CSV 파일 250개 |

| 클래스 | A, B, C, D, E |

| 채널 수 | 2개 |

| 샘플링 주파수 | 1,000 Hz |

| 분석 구간 | 1초\~3초 |

| 윈도우 길이 | 200 ms |

| 이동 간격 | 100 ms |

| 최종 특징 수 | 10개 |



\### 2.2 전처리 과정



1\. 60 Hz 노치 필터와 20\~450 Hz 대역통과 필터를 적용하였다.

2\. 원본 신호에서 1초부터 3초까지의 구간을 추출하였다.

3\. 200 ms 길이의 윈도우를 100 ms 간격으로 생성하였다.

4\. RMS, MAV, WL, ZC, SSC의 시간영역 특징을 추출하였다.

5\. 원본 파일 단위로 학습 데이터와 테스트 데이터를 분리하였다.

6\. 학습 데이터에서 계산한 평균과 표준편차로 표준화를 수행하였다.



두 채널 각각에서 다섯 가지 특징을 계산하여 총 10개의 특징을 사용하였다.



\### 2.3 데이터 분할



| 항목 | 학습 데이터 | 테스트 데이터 |

|---|---:|---:|

| 원본 파일 | 200개 | 50개 |

| 윈도우 수 | 3,800개 | 950개 |

| 클래스별 윈도우 | 760개 | 190개 |



같은 원본 파일에서 생성된 윈도우가 학습 데이터와 테스트 데이터에 동시에 포함되지 않도록 파일 단위로 분리하였다.

\## 5. 모델 성능 비교



\### 5.1 홀드아웃 평가



Precision, Recall, F1-score는 클래스별 성능을 동일하게 취급하는 macro 평균으로 계산하였다.



| Model | Accuracy | Precision | Recall | F1-score |

|---|---:|---:|---:|---:|

| SVM | 81.16% | 80.86% | 81.16% | 80.89% |

| Random Forest | 78.95% | 78.78% | 78.95% | 78.62% |

| XGBoost | \*\*82.32%\*\* | \*\*82.29%\*\* | \*\*82.32%\*\* | \*\*82.22%\*\* |



XGBoost가 네 가지 평가 지표에서 가장 높은 결과를 보였다. Random Forest는 세 모델 중 Accuracy와 F1-score가 가장 낮았다.



\### 5.2 계산 비용



| Model | 학습 시간 | 샘플당 추론 시간 |

|---|---:|---:|

| SVM | 0.274초 | 0.2463 ms |

| Random Forest | 0.524초 | 0.0550 ms |

| XGBoost | 6.086초 | 0.0359 ms |



이번 실행 환경에서는 XGBoost의 학습 시간이 가장 길었지만 샘플당 추론 시간은 가장 짧았다. 계산 시간은 실행 환경과 소프트웨어 버전에 따라 달라질 수 있다.



\### 5.3 5-fold 교차검증



| Model | Fold 1 | Fold 2 | Fold 3 | Fold 4 | Fold 5 | 평균 정확도 ± 표준편차 |

|---|---:|---:|---:|---:|---:|---:|

| SVM | 79.37% | 80.74% | 81.68% | 80.11% | 78.84% | 80.15 ± 1.00% |

| Random Forest | 79.79% | 80.53% | 81.05% | 78.00% | 78.63% | 79.60 ± 1.14% |

| XGBoost | 82.84% | 83.26% | 83.16% | 80.11% | 81.16% | \*\*82.11 ± 1.26%\*\* |



| Model | Macro F1 평균 ± 표준편차 |

|---|---:|

| SVM | 0.7988 ± 0.0105 |

| Random Forest | 0.7940 ± 0.0122 |

| XGBoost | \*\*0.8199 ± 0.0130\*\* |



교차검증에서도 XGBoost가 가장 높은 평균 정확도와 Macro F1을 보였다.



이번 교차검증은 전체 250개 파일을 대상으로 수행하였다. 따라서 원래의 홀드아웃 테스트에 사용된 파일도 교차검증에 포함되며 두 평가 결과는 완전히 독립적이지 않다.



\## 6. 통계 검정



다섯 폴드의 정확도를 이용해 대응표본 t-검정을 수행하였다. 유의수준은 0.05로 설정하였다.



| 모델 비교 | t 통계량 | p-value | 판정 |

|---|---:|---:|---|

| SVM vs Random Forest | 1.2904 | 0.266464 | 유의한 차이를 검출하지 못함 |

| SVM vs XGBoost | -3.3537 | 0.028472 | 유의함 |

| Random Forest vs XGBoost | -13.6502 | 0.000167 | 유의함 |



보정하지 않은 p-value를 기준으로 SVM과 XGBoost, Random Forest와 XGBoost 사이에서는 통계적으로 유의한 차이가 나타났다. SVM과 Random Forest 사이에서는 유의한 차이를 검출하지 못했다.



다중비교 보정은 적용하지 않았다. 또한 다섯 폴드의 학습 데이터가 서로 겹친다는 한계가 있으므로 통계 검정 결과를 해석할 때 이를 고려해야 한다.



\## 7. Confusion Matrix 분석



혼동행렬의 행은 실제 클래스이고 열은 예측 클래스이다. 대각선은 올바르게 분류된 데이터이며 대각선 바깥은 오분류된 데이터이다.



\### 7.1 SVM



!\[SVM Confusion Matrix](week3\_results/confusion\_svm.png)



\- 가장 높은 재현율을 보인 클래스: A, 97.89%

\- 최대 오분류 쌍: C → D, 35개



SVM은 A 클래스에서 가장 높은 재현율을 보였다. 반면 실제 C 클래스의 데이터 35개가 D 클래스로 잘못 분류되었다.



\### 7.2 Random Forest



!\[Random Forest Confusion Matrix](week3\_results/confusion\_random\_forest.png)



\- 가장 높은 재현율을 보인 클래스: A, 96.84%

\- 최대 오분류 쌍: C → D, 58개



세 모델 중 C를 D로 잘못 분류한 횟수가 가장 많았다. 전체 Accuracy와 Macro F1 역시 세 모델 중 가장 낮았다.



\### 7.3 XGBoost



!\[XGBoost Confusion Matrix](week3\_results/confusion\_xgboost.png)



\- 가장 높은 재현율을 보인 클래스: A, 96.84%

\- 최대 오분류 쌍: C → D, 42개



XGBoost는 전체 성능이 가장 높았지만 C와 D 사이의 오분류가 남아 있었다.



\### 7.4 오분류 원인 분석



세 모델 모두 C를 D로 오분류하는 현상이 가장 많이 나타났다. 두 클래스의 시간영역 특징이 일부 비슷하거나 현재 사용한 특징만으로 두 클래스를 충분히 구분하기 어려웠을 가능성이 있다. 다만 혼동행렬만으로 원인을 확정할 수는 없으며 원본 신호와 클래스별 특징 분포를 추가로 비교할 필요가 있다.



\## 8. 최종 결과



홀드아웃 평가와 5-fold 교차검증 모두에서 XGBoost가 가장 높은 평균 분류 성능을 보였다. 홀드아웃 정확도는 82.32%였으며 5-fold 평균 정확도는 82.11 ± 1.26%였다.



XGBoost는 학습 시간이 가장 길었지만 샘플당 추론 시간은 가장 짧았다. 세 모델 모두 C를 D로 오분류하는 경향이 있어 전체 지표뿐 아니라 클래스별 오류도 함께 살펴봐야 한다.



이번 실험을 통해 모델을 비교할 때는 Accuracy뿐 아니라 Precision, Recall, F1-score, 혼동행렬, 교차검증, 통계 검정 및 계산 비용을 함께 확인해야 한다는 점을 알 수 있었다.



\## 9. 한계 및 개선 방향



첫째, 현재 실험은 250개 원본 파일을 대상으로 수행했으므로 다른 데이터나 처음 보는 사용자에게도 같은 성능이 나타나는지는 확인하지 못했다.



둘째, 두 채널에서 추출한 10개의 시간영역 특징만 사용했다. 주파수영역 특징이나 다른 특징 추출 방법을 추가하면 C와 D 사이의 오분류가 줄어드는지 확인할 수 있다.



셋째, 교차검증은 전체 파일을 대상으로 수행하였으므로 기존 홀드아웃 테스트와 완전히 독립된 평가가 아니다.



넷째, 통계 검정은 다섯 폴드의 정확도에 기반하며 다중비교 보정을 적용하지 않았다. 폴드 간 학습 데이터가 겹치는 점도 결과 해석의 제약이다.



다섯째, 학습 및 추론 시간은 현재 CPU 환경에서 측정한 값이므로 다른 환경에서는 달라질 수 있다.
